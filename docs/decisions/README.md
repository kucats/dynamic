# Architecture Decision Records

Record decisions that materially change architecture, protocol, schema, security boundaries, operational ownership, or long-term maintenance cost.

Use `0000-template.md`, assign the next four-digit number, and keep the record immutable after acceptance except for status or links to superseding decisions.

Statuses:

- `proposed`
- `accepted`
- `deprecated`
- `superseded by ADR-NNNN`

An ADR captures why a choice was made. Implementation detail and current progress belong in Issues, execution plans, and source code.
