# ホルンの運指表記（DYNAMIC リーダーの「運指」行）

## 表記の慣習（調査メモ）

- ロータリー（またはピストン）バルブは左手の指で押さえ、指に番号を振って書く：**1＝人差し指**（全音下げる）、**2＝中指**（半音）、**3＝薬指**（全音＋半音）。
- 何も押さえない音は **0**（開放）。複数押さえる場合は数字を並べて **12**、**23**、**13**、**123** と書く（縦に積んで書く奏者もいる）。
- フルダブル（F／B♭）ホルンは親指レバーで管を切り替える。一般的な運指表は「F管が基本で、親指を押すとB♭管」を前提にし、B♭側の運指に **T**（thumb）を付ける：例 **T0**、**T12**。日本語の運指表では親指レバーを **4**（4番バルブ）と書くものも多い（ヤマハの運指表、GONLOG）。
- 押さえるバルブを番号で並べて書く（例：123）。ただし3本同時の **123** は替え指があるので実際にはほとんど使わない。リーダーではフルダブルのとき 123 の代わりに B♭側の運指（例：C♯3 は T23）を出し、123 は替え指のない音（F管シングルの C♯3、両方の F♯2）にだけ残す。
- 1つの音に替え指がある場合、運指表では左（先頭）が第一候補、右が替え指として並べるのが一般的。
- 書き込みは音符の上下に小さく。ゲシュトップの **+** や開放の **o** と紛れないよう、開放バルブは数字の **0** で書く。
- 手のサインで伝える場合も同じ番号づけ：親指に付けた指が「押さえている」バルブ（例：人差し指を親指に付ける＝1、中指と薬指＝23）。

## リーダーでの実装

- 表示する行に **運指**（紫）を追加。既定はオフで、設定から行ごとにオン／オフできる（パートごとに保存）。
- 運指は各音の **F管の読み**（`n.f` の MIDI 番号）から `public/reader/horn-fingerings.json` を引いて求める。in D や in C のパートも F管の読みに直してから引くため同じ表で扱える。
- 設定：
  - 楽器：フルダブル（F／B♭）または F管シングル。
  - B♭側（T）を先にする音：運指表どおり（既定）、または G4／G♯4／A4 から上。指定した音より上では T の運指を、下では F側の運指を第一候補にする。
- 現在の音の表示とロングトーン練習の画面には、第一候補と替え指を表示する。
- 印刷用 URL では `rows=wv`、`horn=F`、`switch=69`（`switch=0` で運指表どおり） のように指定できる。

## 運指表の出典と検算

- 表は [ヤマハ 楽器解体全書「ホルンの運指表」（PDF）](https://www.yamaha.com/ja/musical_instrument_guide/common/images/horn/fingering.pdf) の「Fシングル」欄と「F/B♭フルダブル」欄を1音ずつ写した。表の左側が第一候補、右側が替え指（同PDFの注2）。
- フルダブル欄では、低音の D3・E♭3・E3・F3 と、A4 から上は B♭側（T）が第一候補。G4・G♯4 は F側（0・23）が第一候補で、T1・T23 は替え指。
- 最初の版は倍音列から自作した表だったが、ヤマハの表と次の点が違ったので置き換えた：A4（T0 → **T12**）、G♯4（T2 → **23**、替え T23）、E3・F3（F側 → **T2・T0**）、C♯5 のFシングル（12 → **2**、替え 12）。
- [GONLOG（権左勇一）の運指表の解説](https://gonzayuichi.com/fingering)：フルダブルは基本的に B♭の指使いでよいが、五線内の C と H（とそのオクターブ下）は F管の方が音程・音色がはまりやすい。真ん中の G や D はピッチが高くなりがちなので、強奏では 12 の代わりに 3 を使う替え指がある。
- 検算：`tests/test_horn_fingering.py` が、すべての運指が開放倍音に届くこと（F管は C2 を基音とする倍音、B♭側はその完全4度上）、低めの第7・第14倍音を第一候補にしていないこと、123 は替え指のない音にだけあること、公開中のホルンパートの全音符に運指があることを確かめる。バルブの下げ幅は 2＝1半音、1＝2半音、3＝3半音（12＝3、23＝4、13＝5、123＝6半音）。

## 限界

- 表はヤマハの運指表に基づく第一候補の **目安** で、原譜の指示でも、奏者や指導者が確かめた運指でもない。楽器（シングルB♭、ディスカント、B♭が基本のフルダブル）や奏者の習慣、音程の補正で変わる。
- 音符の音高そのものの監査状態は各パートの「説明」のとおり。運指は転記された音高から機械的に求めるので、要確認の音は運指も要確認になる。
