# ホルンの運指表記（DYNAMIC リーダーの「運指」行）

## 表記の慣習（調査メモ）

- ロータリー（またはピストン）バルブは左手の指で押さえ、指に番号を振って書く：**1＝人差し指**（全音下げる）、**2＝中指**（半音）、**3＝薬指**（全音＋半音）。
- 何も押さえない音は **0**（開放）。複数押さえる場合は数字を並べて **12**、**23**、**13**、**123** と書く（縦に積んで書く奏者もいる）。
- フルダブル（F／B♭）ホルンは親指レバーで管を切り替える。一般的な運指表は「F管が基本で、親指を押すとB♭管」を前提にし、B♭側の運指に **T**（thumb）を付ける：例 **T0**、**T12**。日本語の運指表では親指レバーを **4** と書くことが多い（ヤマハの表は 4・3・2・1 の4段、GONLOG は「親指を4と表記する場合が多い」と注記）ほか、F／B♭ の2段に分けて書くものもある。リーダーは写真のハンドサインに合わせて T を使う。
- 押さえるバルブを番号で並べて書く（例：123）。ただし3本同時の **123** は替え指があるので実際にはほとんど使わない。リーダーではフルダブルのとき 123 の代わりに B♭側の運指（例：C♯3 は T23）を出し、123 は替え指のないF管シングルの最低音域（F♯2・C♯3）にだけ残す。
- 1つの音に替え指がある場合、運指表では左（先頭）が第一候補、右が替え指として並べるのが一般的。
- 書き込みは音符の上下に小さく。ゲシュトップの **+** や開放の **o** と紛れないよう、開放バルブは数字の **0** で書く。
- 手のサインで伝える場合も同じ番号づけ：親指に付けた指が「押さえている」バルブ（例：人差し指を親指に付ける＝1、中指と薬指＝23）。

## 原典との突き合わせ（2026-09-24）

ネットワーク制限が解除されたので、次の2つの運指表を読み、倍音列から作った表と1音ずつ比べた。

- ヤマハ「楽器解体全書」ホルンの運指表（Fシングル／B♭シングル／F/B♭フルダブルの3段、左が第一候補・右が替え指、G4 付近から上に「ダブルホルンの場合、通常はB♭に切り替えて演奏する音域」の点線）。
- GONLOG「ホルンの運指表（F/B♭フルダブル、Fシングル用、替え指有）」PDF（F管・B♭管それぞれの運指、括弧内が替え指）。本文では「フルダブルは基本B♭、ただし五線の中の C・H とその1オクターブ下（C5・B4・C4・B3）は F 管」を勧めている。

第一候補はフルダブルの段をヤマハに合わせ、GONLOG で確かめた。直したところ：

| 音（F管記譜） | 以前 | 現在 | 根拠 |
| --- | --- | --- | --- |
| A4 | T0 | **T12**（替え T0・T3） | ヤマハ・GONLOG とも 12 |
| G♯4（B♭側） | T2 | **T23**（替え T2） | 両表とも 23 |
| D5 | T12（替え T3・T2） | T12（替え **T3** のみ） | T2 は第7倍音で両表に無い |
| C♯5（F側） | 12 | **2**（替え 12） | 両表とも 2 |
| C♯5（B♭側）替え | T1 | 削除 | 両表に無い |
| G♯5・A5 | T2・T0 | **T23・T12** | 両表とも |
| C♯3〜F3（フルダブル） | F側（123・13・23・12・1） | **T23・T12・T1・T2・T0** | ヤマハのフルダブル段。GONLOG の B♭ 側も同じ |
| 切り替え位置の既定 | G♯4 | **A4** | ヤマハのフルダブル段は G♯4 まで F 側（23）、A4 から B♭ 側 |

替え指はどちらかの表に載っていて、倍音列で検算できるものだけを残した（例：E3・A3 の 3、G3 の 13、E4 の T13）。GONLOG の高音域の替え指には第11・13倍音を使うものがあり、倍音表で検算できないので載せていない。

## リーダーでの実装

- 表示する行に **運指**（紫）を追加。既定はオフで、設定から行ごとにオン／オフできる（パートごとに保存）。
- 運指は各音の **F管の読み**（`n.f` の MIDI 番号）から `public/reader/horn-fingerings.json` を引いて求める。in D や in C のパートも F管の読みに直してから引くため同じ表で扱える。
- 設定：
  - 楽器：フルダブル（F／B♭）または F管シングル。
  - B♭側（T）に切り替える音：F♯4／G4／G♯4／A4（既定、ヤマハ式）から上。フルダブルでは切り替え位置にかかわらず C♯3〜F3 も B♭ 側。
  - 「ほぼ全部」（GONLOG 式）：B3・C4・B4・C5 と、B♭ 側が 123 になる F♯3 以外はすべて B♭ 側。
- 現在の音の表示とロングトーン練習の画面には、第一候補と替え指を表示する。
- 印刷用 URL では `rows=wv`、`horn=F`、`switch=68`（`switch=0` で「ほぼ全部」）のように指定できる。

## 運指表の作り方と検算

- 最初は運指表サイトを取得できなかったため倍音列から算出し、その後ヤマハと GONLOG の表で第一候補を直した（上の表）。
- F管の開放倍音（記譜）：C3, G3, C4, E4, G4, (B♭4), C5, D5, E5, G5, …。B♭側はその完全4度上：F3, C4, F4, A4, C5, (E♭5), F5, G5, A5, C6。
- 各バルブの下げ幅：2＝1半音、1＝2半音、3＝3半音（12＝3、23＝4、13＝5、123＝6半音）。
- `tests/test_horn_fingering.py` が、すべての運指が開放倍音に届くこと、低めの第7倍音を第一候補にしていないこと、フルダブルの第一候補（既定設定）がヤマハの表と一致すること、「ほぼ全部」で C・H が F 管に残ること、公開中のホルンパートの全音符に運指があることを確かめる。

## 限界

- 表は一般的な第一候補の **目安** で、原譜の指示でも、奏者や指導者が確かめた運指でもない。楽器（シングルB♭、ディスカント、B♭が基本のフルダブル）や奏者の習慣、音程の補正で変わる。
- 音符の音高そのものの監査状態は各パートの「説明」のとおり。運指は転記された音高から機械的に求めるので、要確認の音は運指も要確認になる。
