# Handoffs

Use a handoff when another human or agent must continue unfinished work. The active GitHub Issue remains the coordination record; a file in this directory preserves exact technical state when the detail is too large for a comment.

Name handoffs `YYYY-MM-DD-issue-<number>-<slug>.md` and start from `TEMPLATE.md`.

Update an existing handoff for the same attempt rather than creating conflicting copies. Mark superseded handoffs clearly.
