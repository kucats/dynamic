# Dvořák 8 / Trombone II

Source PDF hash and page span are recorded in `project.json`. `notes/` carries both reviewed notes and the rendered note model; `timing/` carries explicit duration/rest/tie tokens and the processing receipt; `reviews/` carries structural and browser/offline-audio QA. The public HTML and two PDF layouts are in `public/artifacts/dvorak/symphony-no-8/trombone-ii/`.

The player supports continuous synthesized practice playback with score following, tempo, repeat control, seeking, single-note audition, and movement selection. The source score remains visible; highlighting does not cover notes. The generated sound is not aligned to the cited YouTube recording. The existing UI/audio QA is not a musician's independent listening review.
